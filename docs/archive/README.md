# Archive — frozen reports

These documents are point-in-time audits, design reviews, and implementation notes. They are preserved for history and **must not be treated as current** — product behavior, file layouts, and checklists described here may be outdated. For the present state, start at [`docs/`](../).


> **Deployment warning:** never use files in this archive to host/update Echoo.
> Current operators and AI agents must start with
> [../../HOSTING.md](../../HOSTING.md) and [../../AGENTS.md](../../AGENTS.md).
> In particular, the current backend requires FFmpeg + FFprobe for automatic
> server MP3 replay and trimming.
