# Echoo Listener Mobile V2

Validation branch for the listener-first mobile revamp.

Current scope:
- Listener Home matching the approved light/dark direction
- Home, Library, Search, Favorites and Profile navigation
- Secure mobile session storage
- Real saved audio, followed stations and listening history
- Station profiles and follow state
- Published audio player
- Receive-only LiveKit listener rooms
- Listener settings and menu surfaces
- Mobile lint and TypeScript CI gate

This integration branch exists to validate the mobile revamp before any merge to `main`.
